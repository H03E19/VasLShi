
# 🚀 پروژه وصلشی

سامانه فروش حرفه‌ای بر پایه 3X-UI

---

## 🧩 معرفی پروژه

> سیستم فروش و مدیریت سرویس با معماری مدرن، جدا از هسته 3X-UI و مبتنی بر API امن

---

## 📌 ویژگی‌ها

<details>
<summary>🔌 معماری API مستقل</summary>

- طراحی کاملاً جدا از هسته 3X-UI  
- بدون وابستگی به فایل‌های داخلی پنل  
- ارتباط فقط از طریق API استاندارد و امن  
- افزایش امنیت کلی سیستم  
- جلوگیری از خطا هنگام آپدیت پنل  
- توسعه‌پذیری بالا  
- ساختار ماژولار و قابل گسترش  
- مناسب پروژه‌های بزرگ و پایدار  

</details>

---

<details>
<summary>💻 توسعه با Go</summary>

- توسعه کامل با زبان Go  
- سرعت بسیار بالا  
- مدیریت همزمانی درخواست‌ها  
- مصرف منابع کم و بهینه  
- مناسب سیستم‌های پرترافیک  
- پایداری بالا در سطح سرور  
- پاسخ‌دهی سریع  
- مناسب مقیاس‌پذیری آینده  

</details>

---

<details>
<summary>👤 داشبورد کاربری</summary>

- داشبورد اختصاصی برای هر کاربر  
- نمایش لحظه‌ای سرویس‌های فعال  
- مشاهده تاریخ انقضا و وضعیت اشتراک  
- گزارش دقیق مصرف  
- امکان تمدید سریع سرویس‌ها  
- مدیریت تراکنش‌ها و پرداخت‌ها  
- رابط کاربری ساده و موبایلی  
- تجربه کاربری سریع و بدون پیچیدگی  

</details>

---

<details>
<summary>💰 کیف پول داخلی</summary>

- سیستم کیف پول داخلی  
- شارژ حساب از طریق کارت‌به‌کارت  
- پشتیبانی از ارزهای دیجیتال  
- نمایش لحظه‌ای موجودی  
- خرید سریع سرویس‌ها  
- امنیت بالا در تراکنش‌ها  
- گزارش کامل پرداخت‌ها  
- ساده‌سازی فرآیند خرید  

</details>

<details>
<summary>📡 اتصال تلگرام</summary>

- اطلاع‌رسانی وضعیت سرویس‌ها  
- مدیریت کاربران از طریق ربات  
- پیام‌های سیستمی خودکار  
- اطلاع‌رسانی لحظه‌ای  
- قابلیت توسعه امکانات بیشتر  
- ارتباط سریع با کاربران  

</details>
